### Paracosm - An offline note taking site made by a system, for systems. 

hey! my name is ezra, and i am the developer of Paracosm. Paracosm is a website made for systems to log alters, take notes, and stay organized.

Key features:
- Paracosm is %100 private. nobody, not even me; can see your data
- create custom boards to keep topics seperate and organized
- log alters names, roles, pronouns, and other notes
- export everything as a JSON file to easily move between devices
- many accessibilty options such as font, text size, dark mode, and more

Paracosm is free to use, requires no account, and runs completely in your browser.
